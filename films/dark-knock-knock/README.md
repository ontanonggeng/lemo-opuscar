# DARK KNOCK-KNOCK JOKES — BLACKSTAR

An original US-English vertical sci-fi sitcom, rendered with the Lemo-Opuscar `styles/scifi-toon/demo/toon.js` screen-space ink engine. A sentient doorbell updates an unsuspecting tenant's lease through increasingly dark knock-knock jokes.

- Format: 540 × 960 preview master, 24 fps, 9:16, H.264/AAC; target approximately 60 seconds.
- Cast: NIX (a nervous orange-jacketed tenant) and DORIS (a sentient purple-gray security door).
- Voice: ElevenLabs v4, separately generated character tracks. DORIS: Joe — Deep Voice Evil Villain Final Boss; NIX: Timmy — Anxious Nerd. Approval refers to owner-directed original text, not a celebrity performance.
- Sound: deterministic synthesized percussive knocks and room tone, cut and mixed with two licensed ElevenLabs generations.
- Brand: BLACKSTAR v5 ECLIPSE CUT, regenerated from the owner-supplied source generator, SHA-256 verified. Replaces all retired anime-derived v4 graphics. Only the abstract mark appears in the end card.
- Source inputs: `dialogue.json`, `voice-sources.json`, `scene.js`, `assemble.py`, `build.sh`.
- Rebuild from GitHub: Actions → Dark Knock Knock Render → Run workflow, after persisted MP3s exist. The initial workflow run fetches and saves MP3s from time-limited ElevenLabs links.
